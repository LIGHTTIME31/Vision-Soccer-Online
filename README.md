# Vision Soccer Online

Vision Soccer Online (VSO) is an indie 11v11 online football game
being developed with Unreal Engine.

## Project Goals

- 11 vs 11 online football gameplay
- One player controls one footballer
- Responsive and realistic dribbling
- Advanced locomotion and direction changes
- Motion Matching based character movement
- Physics-based ball interaction
- Precise foot-to-ball contact system

## Development

The project is currently in active development and prototyping.

Current research areas include:

- Football locomotion
- AI-generated animation
- Motion Matching
- Root Motion
- Animation Warping
- Dribbling and ball-control systems

## Engine

Unreal Engine 5
